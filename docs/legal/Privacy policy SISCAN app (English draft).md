# Data processing policy — SISCAN app (Android)

> **Technical draft**, version 0.3 · in force from November 9, 2026. English translation of
> `politica-datos-app-siscan.md`; the Spanish text prevails. A lawyer must review it before it is published for third
> parties, and a native speaker must review this translation. The same text is shown inside the app in
> **More → Your data and privacy** when the app is in English.

- **Data controller:** SISCAN project (Secado Inteligente de Café), Gobernación de Nariño · CISNA. Contact: to be
  defined by the controller before publishing (pending).
- **What the app stores on the phone:**
  1. The **last dryer status** (readings, batch, equipment, alerts) so it can be shown without signal. This is not
     personal data.
  2. If the person signs in as Dryer manager: their WordPress **username** and **application password**, encrypted in
     the phone's secure storage (Android Keystore), to send commands and record weighings.
  3. Their choices of **theme**, **language**, **notifications** and **fingerprint sign-in**. The language preference
     (`siscan_idioma`) may also be kept as Android's per-app language. They don't identify the person and are deleted
     with "Delete this phone's data".
- **Fingerprint (optional):** the phone's sensor checks it; the app never receives or stores the fingerprint, it only
  unlocks the encrypted credential. It is turned on in More → Fingerprint sign-in, after confirming the fingerprint once.
- **Location (optional, only on request):** used only when an administrator taps "Use my current location" in
  More → Dryer location. It is sent to the CISNA server as the location **of the dryer**, not of the person. It is not
  stored on the phone or used in the background. Android asks for the permission at that moment.
- **Notifications (optional):** if turned on, the app checks the server every 15 minutes (read only) to warn about
  alerts, weighing time and a ready batch, and shows batch progress on the lock screen. Android asks for the permission
  when they are turned on.
- **Smartwatch:** if the person signs in with "Remember me", the phone keeps their session header encrypted with an
  Android Keystore key so SISCAN on the watch can ask it for commands and weighings over the link between watch and phone
  (Wear OS data layer). The watch stores no passwords: it only reads the dryer's public status. It is deleted when the
  person signs out or deletes the phone's data.
- **Artificial intelligence:** the thesis prediction and the neural network run on the CISNA server. The "second
  opinion" is generated by Groq from that server with batch and dryer data; it receives no personal data.
- **What it does NOT do:** it doesn't use the camera or contacts; it has no ads, analytics or tracking; it doesn't share
  data with third parties. The only server it talks to is `cisna.narino.gov.co` over HTTPS.
- **Purpose:** to show the drying status and to let authorized staff record weighings and operate the equipment.
- **Retention:** until the person signs out (which deletes the credential), uses "Delete this phone's data" or
  uninstalls the app.
- **Security:** encrypted credential; HTTPS; the application password can be revoked in WordPress at any time
  (More → Your data → Revoke the application password).
- **Data subject rights** (Colombian Law 1581 of 2012, Decree 1377 of 2013 compiled in Decree 1074 of 2015): to know,
  update, correct and delete their data, and to withdraw the authorization. In the app: **Sign out**, **Delete this
  phone's data** and **Revoke the application password**. The WordPress account data is managed by the site
  administrator.
- **Minors:** the app is for dryer operation staff; it is not aimed at minors.
- **Changes:** a new version will be shown in the app with its date and, if what is processed changes, the
  authorization will be requested again. Version 0.3 only names the language preference, which is not personal data, so
  it doesn't request a new authorization.
